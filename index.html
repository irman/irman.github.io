As the main engineer, I built the payment platform and its merchant integration tools. These included APIs with Lumen and Laravel, an Angular frontend, a popup checkout built with StencilJS, and a PHP Composer package. I also set up private Composer and NPM package repositories.

Laravel Angular StencilJS MySQL Composer Mailgun JWT Docker GitLab Continuous Integration
